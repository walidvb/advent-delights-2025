# 14: Submission receipt email

**What to build:** A Contributor who chose to give an email address receives their edit link by email, so closing the tab does not cost them the ability to fix a typo.

Giving an address stays optional. This is the only mail a Contributor ever receives — there is deliberately no daily "today's Day is open" message.

**Blocked by:** 05, 10

**Status:** ready-for-agent

- [ ] Submitting with an email address sends a receipt containing the edit link and the Calendar's link
- [ ] Submitting without one completes normally and sends nothing
- [ ] The link in the email works and opens that Contributor's own Submission
- [ ] A failure to send does not fail the Submission — the Submission is saved either way and the on-screen edit link is still shown
- [ ] No other automated mail is sent to Contributors
