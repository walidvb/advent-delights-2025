# AGENTS.md

An advent calendar platform: communities create a 25-day calendar, contributors
claim a day and submit two tracks, and the days reveal one at a time through
December.

Read `CONTEXT.md` before working on anything here — it defines the domain
vocabulary, and the terms in it are deliberate.

## Agent skills

### Issue tracker

Issues and specs live as local markdown under `.scratch/<feature-slug>/`, one
file per ticket. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, with label strings equal to their names. See
`docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root. See
`docs/agents/domain.md`.
